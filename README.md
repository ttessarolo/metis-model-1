# Metis Model 1

Questo repository contiene il piano verificabile per costruire **Metis Model 1**:
un adapter locale, basato esclusivamente su **Qwen3.8-27B** e addestrato su Apple
Silicon con MLX, specializzato nella scrittura, modifica, riparazione e revisione
del DSL Metis.

Il punto di ingresso è [`docs/README.md`](docs/README.md).

Il repository non contiene pesi, dataset proprietari, credenziali o payload di
produzione. Ogni futuro artefatto di training dovrà rispettare i confini di
governance e riproducibilità definiti nel piano.
